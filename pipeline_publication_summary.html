RNA-seq Metatranscriptomic AMR Pipeline - Publication Summary

This document summarizes the software stack, computational environments, databases, and workflow of the local RNA-seq metatranscriptomic AMR pipeline implemented in rnaseq_amr_pipeline_app.py.

Publication-release audit addendum

This release bundle was reconstructed from the canonical analysis output at /data/projekty/Metatranskryptomika/2026-05_amr_pipline_test/ and from the source scripts in /data/skrypty/008_Metatransryptom/003_amr_pipeline/. The output directory contains multiple reruns; consequently, the final pipeline_config.json is retained as the last recorded configuration, while pipeline.log and the materialized scripts under provenance/ are the primary evidence for the publication run.

For cross-sample analyses, per-sample assemblies were not treated as one shared transcriptome. Each sample was assembled independently and its CDS features were prefixed with the sample identifier. Salmon matrices were then formed as the union of feature identifiers across samples, with zero counts for features absent from a sample. Functional matrices were generated by aggregating these CDS-level values to KO, EC, PFAM or KEGG Pathway identifiers. The historical one-group exploratory analysis used the CDS count matrix, filtered at count >=10 in at least two samples, followed by DESeq2 vst(blind=TRUE). To address the editor's reproducibility concern, the primary exploratory analysis has now been rerun with the harmonized KO count matrix using code/project_scripts/13_RNAseq_one_group_analysis_KO.R. The corrected analysis generates top-50 and top-100 heatmaps without row clustering and with sample-column clustering; its outputs are in data/figures/rnaseq_one_group_KO/. The original CDS-based results remain available as historical/supplementary outputs.

The analytical unit must therefore be stated explicitly: raw expression matrices are CDS/transcript-feature matrices, whereas KO, EC, PFAM and Pathway analyses compare functional groups. “Genes” should not be used as a generic synonym for these independently assembled transcript/CDS features.

Important audit corrections before submission: the canonical output reports 161,094,476 input reads, 155,542,548 clean reads and 155,531,726 rRNA-free reads; QUAST reports 117,001 contigs for SRR22411016 whereas the corresponding CDS table reports 70,168 CDSs; and the QUAST GC range is 47.34–56.95%. The Pathway matrix also contains both ko... and map... representations, which should be resolved or explicitly justified before final statistical claims are made.

This issue has been addressed in the release by rerunning Pathway aggregation with code/project_scripts/11_KO_to_KEGG_Pathway_deduplicated.R. The corrected matrix contains one normalized mapXXXXX row per pathway, and corrected ALDEx2 and DESeq2 outputs are stored under data/statistics/pathway_deduplicated/. The original matrix and results are retained for traceability.

Suggested Short Methods Paragraph

Paired-end metatranscriptomic RNA-seq reads were processed using a local reproducible workflow. Reads were quality-filtered and adapter-trimmed with fastp, summarized with MultiQC, and screened for rRNA content using Bowtie2 against a SILVA 138.2 rRNA index. rRNA-depleted reads were assembled per sample with MEGAHIT and assembly quality was assessed with QUAST/MetaQUAST. Coding sequences and predicted proteins were inferred from contigs using TransDecoder. Transcript abundance was estimated with Salmon and collected into TPM and count matrices. Predicted proteins were functionally annotated with eggNOG-mapper, and expression matrices were aggregated at KO, EC, PFAM and KEGG Pathway levels. Group-wise comparative analyses were performed on KO and KEGG Pathway count matrices using ALDEx2 and DESeq2, with groups defined by the group_all metadata column. Exploratory one-group RNA-seq summaries were generated using DESeq2 variance-stabilizing transformation, PCA and heatmaps of the top variable genes. AMR analyses combined KO-based AMR summaries with CARD/RGI screening of proteins predicted from TPM-filtered expressed contigs, followed by integration of CARD-derived and KO-derived AMR metrics.

Suggested Figure Caption

Figure 1. Computational workflow for RNA-seq metatranscriptomic AMR profiling. Paired-end reads are trimmed and quality controlled, depleted of rRNA reads, assembled de novo, translated into predicted coding sequences, quantified with Salmon, and functionally annotated with eggNOG-mapper. Count matrices are aggregated to KO, EC, PFAM and KEGG Pathway levels and used for comparative analyses with ALDEx2 and DESeq2. AMR profiling combines KO-based resistance-associated functions with CARD/RGI searches of expressed contigs. MultiQC and a final HTML index summarize pipeline execution and outputs.
